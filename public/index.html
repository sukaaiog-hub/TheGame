    How to Play & Connect

    1. Install the native client: Red Eclipse 2 uses desktop OpenGL (GL_TEXTURE_RECTANGLE) and cannot run inside a browser. Download v2.0.0 from redeclipse.net/download.
    2. Dedicated UDP server: Build redeclipse_server_linux via this repository's GitHub Actions workflow (build-server.yml) and run it on a VPS with public IPv4 and UDP 28801/28802 open.
    3. Link live status: Run status-agent/agent.js next to the server on the VPS and set STATUS_AGENT_URL in Vercel Project Settings.
    4. Join the match: Click Join Server (redeclipse://) or open the in-game console (~) and run the connect command.

    Deployment Split Architecture

    Vercel (Web + Status API) Serves this portal plus /api/status and /api/leaderboard over HTTPS. Serverless functions cannot hold UDP sockets.
    Supabase (Stats + Edge Function) Stores players, matches, match_players, the leaderboard view, and the record-match Edge Function.
    GitHub Actions (Server Build CI) Builds redeclipse_server_linux from redeclipse/base@v2.0.0 via make server and publishes the artifact.
    VPS (UDP 28801 / 28802 + Agent) Hosts the live ENet dedicated server and status-agent/agent.js, bridging raw UDP queries to Vercel over HTTP.
